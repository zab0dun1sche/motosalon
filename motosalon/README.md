## motosalon

Простой адаптивный статический сайт по продаже мототехники (главная, каталог, карточка товара, контакты).

### Как запустить

- Откройте `index.html` в браузере.
- Сайт работает и при открытии через `file://` (данные подключаются через `data/products.js`).

### Структура

- `index.html` — главная
- `catalog.html` — каталог с фильтром по категориям
- `product.html` — страница товара по `?id=`
- `contacts.html` — контакты + карта + форма
- `data/products.js` — данные товаров (легко редактировать)
- `data/products.json` — те же данные в JSON (опционально)
- `assets/styles.css` — стили
- `assets/app.js` — логика страниц
